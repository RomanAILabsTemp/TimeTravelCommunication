🧠 Core Concepts
1. Entropy‑Mapped Lexicon (EML‑300)
4thCom uses a 300‑word English lexicon mapped to entropy codes:

Code

Each entropy value corresponds to a single semantic anchor.
This creates a stable, universal language independent of grammar, culture, or time.

2. Shannon Entropy → Code → Word
User input is converted into:

Shannon entropy

A 1000–4000 code

A mapped word from the lexicon

This allows any text to be reduced to a single entropy‑word.

🔊 The Void: Autonomous Entropy Agent
4thCom includes a background entity known as The Void:

It listens silently every second

If it detects a count word (One–Ten), it begins capturing the next N entropy‑words

Once N words are collected, it emits a full entropy sentence

Example:

Code

The Void can also initiate communication spontaneously.
